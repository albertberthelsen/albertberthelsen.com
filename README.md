# albertberthelsen.com

Personal website of Albert Berthelsen, finance student at BI Norwegian Business School in Bergen.

Plain HTML, CSS and JavaScript with no framework or build step. Hosted on Vercel, and every push to `main` deploys to [albertberthelsen.com](https://albertberthelsen.com).

## Editing

Pages are generated from `scripts/build.py`. Edit the content there, then run:

```bash
python3 scripts/build.py
```
